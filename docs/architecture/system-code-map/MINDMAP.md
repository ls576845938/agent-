# 全系统架构思维导图

`/architecture` 默认视图新增一张以 QuantStation 共享平台为中心的总览思维导图。它解决的是“先看懂全局职责，再进入逐模块源码证据”的导航问题，不是新的运行监控、研究引擎或交易控制面。

## 图的结构

总图固定为六条一级分支：

1. 数据与市场输入：版本化数据、PIT、因子输入、导入入口和证据合同。
2. 共享 Alpha / Qlib 研究：共享工厂、Qlib 适配、BTC 趋势研究及研究注册表。
3. 七层决策职责：Alpha → 市场环境 → 风险 → 组合优化 → 仓位 → 退出／保护 → 执行／账本。
4. BTC / US / CN 执行域：共享合同之下的市场专用装配、风险、执行和账本边界。
5. 前端与服务：统一工作台、后端编排和读模型。
6. 证据与安全治理：不可变上下文、权限门、测试、监控、schema、worktree 与 handoff。

每个叶节点绑定 `catalog.json` 中已经存在的模块 ID。点击后切换到原“模块证据”视图，继续查看模块说明、连接证据、发现和来源文件清单；总图本身不复制逐条 source line，也不从目录名推断连接。

## 图例与事实边界

- 实线节点表示已在源码地图登记职责，不表示当前服务、数据或调用链已经运行成功。
- 虚线节点表示规划中的能力。当前总图没有把未验收规划伪装成已实现节点；市场状态 v2 已实现但条件政策默认关闭，完整 A/B 未通过。
- 七层是职责顺序，不声称七层位于同一个 runtime，也不声称已有统一组合优化器。
- BTC OMS／保护／账本继续是 BTC 执行权威链；共享研究结果不自动进入它。
- 美股和 A 股已有独立执行域，但共享 Alpha 工厂的数据与市场合同尚未全部注册。
- 页面不发送 POST，不运行研究，不读取 secret，不访问 private／order／live endpoint，不授予 promotion、paper 或 live 权限。

## 交互与可访问性

总图使用真正的 SVG 曲线连接与 HTML 按钮节点，不引入外部图形依赖。叶节点支持键盘聚焦和 Enter 激活；提供放大、缩小、适应画布和恢复 100% 控件。大屏优先适应总图，窄屏把水平与垂直滚动限制在画布内部，页面本身不横向溢出。纯文本结构保留为折叠辅助视图。
