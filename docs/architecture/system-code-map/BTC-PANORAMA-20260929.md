## 编辑边界

用户可以在画布中拖动节点、编辑纯文本、增删草稿节点和连线，并使用缩放、适应画布、撤销和重做。编辑结果只可：

1. 显式保存到当前浏览器 `localStorage`；或
2. 导出为标记 `personal_unverified_draft` 的 JSON 文件。

个人草稿不会覆盖内置的原始核验版本，也不会写入后端、源码、研究记录、候选目录、交易配置或权限。页面始终提供“恢复原始版本”，恢复前要求确认，恢复动作可撤销，且只有再次点击保存才会更新本机草稿。

本机草稿读取采用严格版本、来源、大小、节点、连线和引用校验；损坏、超限或来源不匹配时回到原始快照。节点和连线文案均按 React 纯文本渲染，不执行 HTML，不加载草稿中的外部资源或代码。

## 实现选择

画布使用 `@xyflow/react`，仅作为前端构建依赖并随应用打包；没有 CDN 或运行期外部依赖。复用其原生拖动、连线、viewport、缩放和小地图能力，避免另造画布框架。原有架构总览、模块、时间线、证据和图谱视图保持不变。

## 验收口径

- 静态合同必须锁定 A–I、37 个节点、49 条边和关键安全边界。
- 深链刷新和浏览器返回必须保留原页面语义。
- 保存后刷新可恢复；损坏草稿不导致页面崩溃。
- 节点移动、文本编辑、节点／连线 CRUD、撤销、恢复和导出必须有效。
- 页面不得发出候选启动、研究计算、账户、订单或其他写请求。
- worktree 只完成静态、TypeScript 和生产构建验证；正式浏览器验收必须在提交合入当前 `main`、通过唯一 `3000` 端口入口启动后执行。
