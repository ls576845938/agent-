# Position Sizing

## 原则

仓位大小来自预测强度、风险预算、波动率、成本、容量和约束，不来自回测最优杠杆。

## 规则

1. Signal 先转 forecast，forecast 再转 target position。
2. 每个 target position 必须有 sizing reason。
3. 波动率目标必须使用历史可见数据。
4. 仓位变化必须考虑最小下单量和调仓阈值。
5. 单策略仓位不能绕过组合风险预算。
6. 加仓规则必须考虑当前浮亏、回撤和相关敞口。

## BTC-only

- 必须配置最大 BTC 暴露。
- 必须配置现金下限。
- 必须配置最大回撤降仓或停机。
- 永续策略必须限制杠杆和资金费率风险。
