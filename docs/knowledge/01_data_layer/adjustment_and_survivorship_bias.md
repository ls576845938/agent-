# Adjustment And Survivorship Bias

## 适用范围

股票池、ETF 池、期货连续合约、加密货币交易对、复权价格、退市资产。

## 规则

1. 股票池必须记录历史成分，而不是当前成分倒推。
2. 退市、停牌、合并、改名资产必须保留。
3. 复权价格必须记录复权方法和因子可见时间。
4. 期货连续合约必须记录换月规则和可交易合约。
5. 加密交易对必须记录交易所上线/下线时间。
6. 任何 universe filter 都必须可重放。

## 报告要求

策略报告必须说明：

- universe 构建方法。
- 是否包含退市/失效标的。
- 复权和换月规则。
- 数据源缺口。
- 对收益和回撤的潜在影响。
