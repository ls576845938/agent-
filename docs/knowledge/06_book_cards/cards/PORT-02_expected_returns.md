### 第 1 章：预期收益的多源证据与三视角

- **论证链**：expected return 不可观测且实现收益噪声很大，历史表现、资产定价理论、前瞻市场指标和主观观点只能提供互补证据；资产类别、策略风格和底层风险因子三种视角用于识别相同收益来源、集中风险和坏状态暴露。历史均值只有在期望收益近似恒定、样本代表性足够且意外收益可相互抵消时才有解释力。
- **成立条件**：所有输入必须具有同一 horizon、base currency、nominal/real、total/excess、arithmetic/geometric、gross/net 和 benchmark 语义；风险补偿判断需要可观测的 bad-state exposure，前瞻指标需要明确其 unchanged-market-state 假设，主动观点需要独立于已实现结果的形成时间。
- **局限与反例**：起止估值、结构变化、时变风险溢价、幸存者与自愿报告偏差、回测过拟合、低估成本、平滑/陈旧价格和卖尾部保险都会制造漂亮历史记录；独立波动率不能代表坏状态风险，高增长资产也可能因估值过高而低回报。市场数据通常无法唯一识别“理性风险补偿”与“非理性误定价”。
- **项目动作**：建立 `ExpectedReturnEvidence`：记录 as-of、horizon、unit、base currency、nominal/real、total/excess、arithmetic/geometric、gross/net、benchmark、conditioning information、输入来源、风险补偿/误定价/数据幻象三类解释、区间与失效条件；策略只输出 Forecast 或目标，不得绕过 Portfolio/Risk 与 OMS。
- **禁止直接采用**：不得把书中长期均值、历史 premia、Sharpe、风格收益或 60/40 风险结构当当前预测；不得把 carry、value、momentum 或“安全资产”标签直接写成 alpha；不得用回顾性叙事替代 OOS、成本、流动性和尾部证据。

### 第 4 章：expected return 术语与度量合同

- **论证链**：expected return 是 ex ante 且通常不可观测，realized return 是 ex post 结果但不能反推出当时预期；required return 只在价格等于价值且市场出清等条件下与 objective expected return 对齐。预期收益既可描述单资产随时间变化，也可描述同一时点的横截面差异，二者需要不同数据与验证。任何比较还依赖期限、币种、通胀、基准、复利和风险调整定义。
- **成立条件**：历史均值作为预测需要近似恒定的 expected return、无结构变化和足够长样本；real/nominal 必须声明 inflation measure，excess return 必须回答“相对哪个基准”；arithmetic/geometric 分别服务单期决策与财富复利。跨币种比较需分拆 local asset return、FX、hedge cost 和 unexpected-return residual，并说明 covered-interest-parity 的市场与融资条件。

- **项目动作**：统一 `ExpectedReturnEvidence`、`RealizedReturnEvidence` 和 `RiskAdjustedMetric` schema：强制 ex_ante/ex_post、time_series/cross_sectional、expected/required、horizon、simple/log、nominal/real、inflation source、total/excess、benchmark/risk-free、arithmetic/geometric、base currency、hedge、risk-model version、higher moments、liquidity 和 bias flags。IR 与 Sharpe 分开，不允许零基准或 total-return Sharpe 的隐式定义。

### 第 5 章：理性风险定价、多因子与市场摩擦

- **论证链**：资产价格由未来 payoff 与随机折现因子共同决定，expected excess return 是承担系统性坏状态风险的补偿；关键不是 standalone volatility，而是 payoff 与高边际效用状态的协方差。单一市场 beta 过窄，因此多因子模型允许不同风险来源具有不同 beta 与 price of risk；风险和风险厌恶可随时间变化。供需、不可完全替代、融资/流动性摩擦、分歧和委托代理又使相对价格偏离无摩擦均衡，而 return predictability 仍可能与理性学习或 EMH 相容。
- **成立条件**：CAPM 需要单期、可无限无风险借贷、无税费、均值—方差偏好与同质预期；SDF 定价至少需要明确 payoff、状态、计价单位和无套利条件。多因子 premium 要分别识别 factor exposure 与 factor price，且 factor 必须对应可解释的 bad-state hedge/loss；conditional beta/lambda 的 conditioner 只能来自当时信息集。流动性 characteristic、aggregate liquidity beta、交易成本和 funding constraint 必须分开。
- **局限与反例**：bad times 无单一公认 proxy，经验因子容易 data mine，characteristic 与 covariance 解释可竞争；高条件波动并不稳定预测更高近端收益。WDRA/habit、理性学习与情绪模型可能产生近似观测结果；供需效应依赖缺少替代品、做空/融资约束和持有者结构。安全港相关性会在通胀 regime 失效，EMH 的联合假设失败也无法唯一定位市场效率或资产定价模型。

### 第 6 章：行为偏差、套利限制与可利用性

- **论证链**：行为金融需要两个同时成立的支柱：投资者的信念/偏好偏差能系统性改变需求，以及理性套利者因缺少替代品、基本面与 noise-trader risk、外部赎回、margin、stop-loss、成本、模型不确定性和拥挤而无法完全纠偏。启发式、过度自信、损失厌恶、窄框架和低概率加权可解释泡沫、过度交易、value、momentum/reversal 等现象，但相同模式常能由风险补偿、学习或市场摩擦解释。
- **成立条件**：behavioral hypothesis 必须给出可观测偏差 proxy、资产需求传导、fundamental value/benchmark、纠偏主体、替代品与 hedge、资本/borrow/funding、预测期限、催化剂和 decay；bubble/reflexivity 模型还需区分触发、放大、叙事、social transmission 与 credit/leverage。value/momentum 研究必须用 PIT universe、真实持有者/成本、可交易 long-short、成本和 capacity 验证。
- **局限与反例**：行为故事过多且易事后适配；prospect theory 单独缺少具体资产预测，reference point 与 framing 会改变结论。宏观错价比相对错价更难对冲，mispricing 可在套利者先破产前继续扩大。published anomaly 可能因 data mining 或学习衰减；短期 reversal 也可能只是 bid–ask bounce/price concession。理性 risk premium、rational learning 与 irrational sentiment 在历史数据中常不可识别。
- **项目动作**：`BehavioralHypothesisEvidence` 保存 bias、observable proxy、information strength/weight、reference point、holder cost basis、flow/turnover、valuation anchor、substitute/hedge、borrow/funding/margin、crowding/downside correlation、catalyst、half-life、trial count、alternative explanations 和 falsifier。研究评估同时报告 gross signal、可投资实现、cost/capacity、危机 unwind 和 publication-decay；团队决策使用预注册反证清单抵御 confirmation/hindsight。
- **禁止直接采用**：不得把“投资者非理性”、Minsky、reflexivity、animal spirits、prospect theory、disposition 或 lottery preference 当信号；不得迁移“两倍损失厌恶”、12 个月 momentum/36 个月 reversal、历史泡沫、情绪季节或 holder cost-basis 规则；不得因 behavioral story 合理就授权 active trading、杠杆或放宽 gate。
- **L3 待复核**：`FORM-PORT02-CH06-001`—`025`。

### 第 7 章：竞争解释、统计幻象与不可识别性

- **论证链**：return predictability 或横截面高平均收益至少有四类竞争解释：时变风险补偿、行为误定价、样本/统计幻象，以及真实但已因摩擦或结构变化失去可投资价值的历史规律。discount-rate 下降会同时抬高当期 realized return、降低未来 expected return；误定价机会则应随公开、套利资本和拥挤呈生命周期。data mining、fund reporting bias、未实现稀有灾难、理性学习、交易摩擦和制度断点都会制造“过去存在、未来不可用”的记录。
- **成立条件**：风险溢价解释需给出 bad-state loss 与投资者特定承受能力；误定价解释需给出 fundamental anchor、arbitrage mechanism、capital/capacity 和 publication-decay；mirage 检查必须覆盖完整 trial universe、纯 OOS/交叉验证、实时可得变量、survivorship/backfill、rare-event exposure、structural learning、成本/impact/borrow/funding 与制度变化。无法区分时必须保留 unresolved，而不是强行择一。
- **局限与反例**：高 expected return 往往在市场参与者风险厌恶最高时出现，不是所有投资者的免费时机；micro opportunity 更易对冲但也更易拥挤，macro opportunity 容量更难获得。真实机会 OOS 衰减可能来自 overfit、学习、竞争或结构断点，单凭衰减不能识别原因。样本未见灾难会令卖保险异常漂亮，逐渐学习结构变化也会产生看似系统性预测误差。
- **项目动作**：每项 CandidateEvidence 固定四栏 `risk_premium / mispricing / mirage / structural_break`，分别记录预测、证据、反例、可证伪条件、当前权重和 unresolved reason；trial ledger 覆盖失败候选与集体研究先验，OOS 按 publication/implementation 时间切分。策略 underperformance 只能触发预定义的 thesis audit、risk reduction 或 expiry，不允许事后 double-down/cut-loss 叙事。
- **禁止直接采用**：不得把“长周期/深口袋”当自然优势，必须由资金、负债、margin 与治理证明；不得把 historical carry、value、momentum 或未发生灾难的样本当 premium；不得以经济故事、普通 robustness 或 rolling coefficient 宣称消除 collective data mining；不得因解释不可识别而放宽 promotion gate。
- **L3 待复核**：`FORM-PORT02-CH07-001`—`014`。

### 第 8 章：Equity Risk Premium 的多方法证据

- **论证链**：ERP 必须先区分相对 cash 还是 long bond、ex post 还是 ex ante、nominal/real、arithmetic/geometric 与 objective/subjective。历史 premium 混合通胀、估值扩张、幸存者/easy-data/peso bias 和一次性 bond repricing；前瞻 DDM 将 equity return 拆成 payout yield、per-share growth 与 valuation change，再减长期 real/nominal bond yield。调查反映投资者主观预期，常与客观估值反向；战术 predictor 覆盖 valuation、money/credit、real activity、risk、sentiment/technical 和 seasonals，但高度集中且 OOS 脆弱。
- **成立条件**：历史估计需 broad cap-weighted PIT index、同期限 benchmark、税费/成本、全球失败市场和 endpoint adjustment；payout 必须包含 dividend、buyback、issuance，增长必须以 existing-shareholder 的 per-share growth 而非 GDP/aggregate profit 替代。DDM 的 payout、growth、inflation、bond maturity、steady-state 和 no-multiple-change 假设均需敏感度；survey 记录 respondent、question、horizon、发布时间；tactical model 只用实时 vintage、预注册 predictor/horizon 与 rolling OOS。
- **局限与反例**：美国和 20 世纪是特殊成功样本，股票可在数十年内落后长债；repricing-adjusted 历史 premium 仍不是当前 premium。dividend yield 受 buyback 制度变化破坏，Fed Model 混合真实 earnings yield 与 nominal bond yield；EPS 长期落后 GDP，原因包括新企业和净发行稀释。DDM 是稳态近似，G 最不受锚定。零售/分析师预期追涨且过度乐观，长周期 predictive correlation 受重叠窗口、低 breadth、均值漂移和 hindsight 污染。
- **项目动作**：`EquityPremiumEvidence` 同时输出 historical、repricing-adjusted、payout-growth DDM、earnings-yield/Fed-model diagnostic、survey 和 tactical 六套估计，记录 cash/bond benchmark、PIT index、inflation、payout/issuance、EPS dilution、growth source/vintage、valuation-change assumption、survey cohort、forecast interval 与方法间 disagreement。Portfolio 只能把区间作为 strategic/risk context；timing 另走预注册、成本后、集中度和 re-entry 验证。
- **禁止直接采用**：不得迁移书中 3%—8% ERP、4% adjusted premium、1% EPS growth、60% payout、任何 survey 数字、Fed Model 阈值或 predictor correlation；不得把 GDP growth 当 EPS floor，也不得把估值便宜直接变仓位。所谓长周期优势必须由资金、负债、流动性和治理证明；Agent 不得用 ERP 文献绕过 holdout、Portfolio/Risk 或 promotion evidence。
- **L3 待复核**：`FORM-PORT02-CH08-001`—`032`。

### 第 9 章：Bond Risk Premium、利率预期与期限风险

- **论证链**：BRP 是 long-duration default-free bond 相对 rolling short bonds 的 ex ante excess return，不等于历史平均超额收益或 curve steepness。债券收益由 yield income、rolldown 与 yield-change capital gain/loss 构成；long yield 又可拆为未来 short-rate expectation、expected inflation/real rate 和 term premium。曲线斜率同时承载均值回归的利率预期与风险补偿，短期可能预测 excess return，长期却可能主要预测 short-rate normalization。BRP 的长期变化由 inflation uncertainty、stock-bond safe-haven covariance、供需/segmentation 和周期共同驱动。
- **成立条件**：所有 BRP 估计必须声明 horizon、maturity/duration、coupon/zero/par curve、risk-free roll、yield/return 口径、survey/model expectations、inflation vintage、convexity 与 rolldown。PEH、random-walk、Cochrane–Piazzesi、Kim–Wright 和 survey BRP 是竞争代理而非真值；模型要保存 state variables、no-arbitrage specification、survey measurement error 和 estimation interval。safe haven 必须按 stock-bond correlation、inflation/growth regime 与 crisis horizon 验证。
- **局限与反例**：历史 duration reward 被 1981 年前后 yield trend 主导，front-end 高 Sharpe 来自 Treasury bill scarcity、融资不对称和市场分割，不是无风险套利。1980—1982 曲线倒挂但长期 BRP 高，说明 curve shape 可被 mean-reverting rate expectations 污染。survey 也有测量误差，宏观期限结构模型可能 misspecify；stock-bond correlation 会换符号。财政、QE、养老金规则、foreign flow 和央行沟通的历史影响高度制度依赖。
- **项目动作**：`BondPremiumEvidence` 同时保存 realized return decomposition、curve slope/curvature、forward rates、survey expected short rates/inflation、model term premium、ex ante real yield、duration/convexity/roll、stock-bond beta/correlation、fiscal maturity supply、regulatory/foreign flows、cycle/monetary-policy state 与 method disagreement。Portfolio/Risk 把 nominal bond 分别压力测试 inflation shock、real-rate shock、safe-haven loss、curve twist、funding/market-liquidity 与 sovereign concerns；duration timing 与 static hedge 分账。
- **禁止直接采用**：不得迁移 1% historical BRP、front-end Sharpe、C-P tent coefficients、3%—4% inflation premium、任何 yield-impact 或 predictive correlation；不得把陡峭曲线机械解释为高 BRP，也不得把 Treasury 恒定视为 riskless/safe haven。duration momentum、curve signal 或 survey premium 未经实时 OOS、成本、重叠样本与 regime 验证，不得进入策略或 gate。
- **L3 待复核**：`FORM-PORT02-CH09-001`—`031`。

### 第 10 章：Credit Risk Premium、损失分解与非政府债

- **论证链**：corporate–Treasury spread 首先补偿预期 default/downgrade loss 与 embedded option，再可能包含 systematic credit premium、illiquidity、税负、Treasury convenience yield 和其他模型残差，因此 spread、OAS、ex ante excess return 与 realized excess return 不能互换。默认相关性、低回收率、波动与流动性恶化在衰退中共振，使信用近似卖出坏状态保险；历史 IG 超额收益很低，fallen angels 与短久期高评级的表面优势又受到 index forced selling、市场分割、Treasury scarcity、融资成本和危机集中亏损影响。swap、CDS、MBS、EM debt 进一步表明同一“非政府 spread”可由银行系统风险、现金—衍生品 basis、负凸性/提前偿还模型、主权基本面和一次性 spread compression 驱动。
- **成立条件**：信用证据必须以 duration-matched、可交易、PIT universe 和真实 index rules 重建，区分 issuer/issue weighting、rating migration、default probability、recovery/LGD、spread duration、roll、optionality、tax、liquidity、bid–ask、funding、collateral、capital 和 benchmark convenience yield。结构式、reduced-form、risk-neutral/real-world PD、OAS/prepayment 与 tactical predictor 都必须保存模型版本、校准窗口、实时输入、拟合残差、替代模型和 OOS 误差；portfolio credit 还需 default correlation 与 clustered loss stress。
- **局限与反例**：旧 corporate 数据存在期限错配、未扣 downgrade/default 和 stale pricing，低波动/低相关被高估；risk-neutral 与 real-world 概率之差只有在模型正确时才可解释为 premium，残差也不能自动命名 liquidity。front-end 高 Sharpe 在 LIBOR/repo funding 与 leverage constraint 后下降，并在 1998、2007—2008 等坏状态集中受损。评级、default/recovery 是滞后且内生的，spread lead 不等于因果；历史 tactical correlations、MBS OAS、EM debt 高收益都受到短样本、模型误差、政策支持和一次性重估污染。
- **项目动作**：`CreditPremiumEvidence` 输出 raw spread/OAS、benchmark、duration/convexity/option exposure、PD/LGD/default correlation、migration/forced-flow loss、liquidity/funding/collateral/capital、cash-CDS basis、cycle/volatility/recovery state、sovereign risk、model residual 与 forecast interval。美股信用 ETF 仅作风险状态和防御资产候选：分别压力测试 Treasury safe-haven 失效、spread widening、default/recovery clustering、liquidity freeze、funding shock 与 index turnover；BTC 不把传统 credit spread 机械迁移为 funding/carry 信号。
- **禁止直接采用**：不得迁移 30 bp IG premium、40% recovery、历史 rating spread、front-end Sharpe、spread/duration cushion、任何 tactical correlation、swap spread、MBS OAS、EMBI 收益或 threshold；不得把 fallen angels、short credit、CDS basis、MBS negative convexity 或 wide spread 直接变成策略。无当前数据、法律/合约语义、成本、流动性、风险模型、Portfolio/Risk 和独立 OOS 证据时，不得实施信用 alpha、杠杆或 promotion。
- **L3 待复核**：`FORM-PORT02-CH10-001`—`034`。

### 第 11 章：另类资产溢价、平滑偏差与可实现收益

- **论证链**：房地产和商品更接近资产类别，HF 与 PE 更接近委托式主动策略；四类“另类”共同具有较低透明度、较高费用、有限容量和流动性，只在正常时期看似改善分散化，2008 年则暴露共同的 equity、credit、liquidity、leverage 与 short-tail beta。房地产 total return 主要来自净租金/现金收益而非长期真实价格增长，但 appraisal smoothing 会压低波动与相关；commodity futures return 必须包含 spot、collateral 与 roll，backwardation 只有在 spot/constant-maturity random-walk 条件下才可近似 expected premium。HF/PE 的 reported alpha 又被自愿报告、幸存/回填、非流动 marking、非线性 beta、高额费用、capital calls 和 top-manager access 重新分配。
- **成立条件**：跨资产比较必须统一 total/price return、arithmetic/geometric/IRR、cash collateral、leverage、fees/taxes/capex、marking lag、benchmark、currency 与 liquidity horizon。private real estate/HF/PE 需恢复 stale return、lagged beta、downside/tail risk 和 cash-flow timing；commodity 要按真实合约、roll schedule、margin income、index weights 与可交易成本重建。manager skill 必须在完整 live/dead/non-reporting universe、gross-to-net waterfall、多因子模型、capacity、access 与投资者 dollar-weighted return 后仍成立。
- **局限与反例**：appraisal 或 IRR 平滑会制造虚假低风险，REIT 又混入 equity beta，二者都不是无偏“真实地产”。rental/cap rate 会受 capex、税、融资、供需和估值变化影响；commodity generic price series 忽略 roll，历史能源优势和 index redesign 受样本与 hindsight 污染。HF alpha 随风险模型扩展可被重分类为 alternative beta，未解释残差仍混合 luck、bias 和 omitted risk；PE gross skill 可能主要被 GP 费用捕获，top-quartile persistence 受 access、vintage 和 smoothing 限制。
- **项目动作**：`AlternativePremiaEvidence` 按 `real_estate / commodity_futures / hedge_fund / private_equity` 分域保存 cash-flow/roll decomposition、valuation/marking source、freshness、leverage、liquidity terms、capital commitment/call、factor/downside/tail beta、gross/net fee waterfall、reporting-universe coverage、manager/fund vintage、capacity/crowding 与 forecast interval。组合层仅把可复制、成本后、危机相关和流动性一致的 exposure 纳入风险预算；本项目当前不把外部 HF/PE manager selection 变成交易或 promotion 证据。
- **禁止直接采用**：不得迁移房地产历史回报、0% real HPA、租金/资本化率阈值、commodity roll/momentum 数字、HF Sharpe/alpha、2+20、PE IRR、top-quartile persistence 或 vintage 规则；不得把 illiquidity premium、negative skew、alternative beta 或 Yale 式 access 当可免费复制优势。无 current PIT 数据、完整失败样本、合法可交易工具、成本/容量/流动性压力和独立 OOS 时，不得据此增配、加杠杆或解锁任何 gate。
- **L3 待复核**：`FORM-PORT02-CH11-001`—`048`。

### 第 12 章：Equity Value Premium、收敛机制与结构断点

- **论证链**：value strategy 用价格相对 book、earnings、cash flow、dividend、sales 或 enterprise value 的便宜程度建立动态 long–short 暴露；历史收益主要不是永久高增长，而是 yield 优势、盈利均值回归、valuation convergence 和公司跨 value/growth 组迁移。行为解释强调投资者把高增长外推过久，理性解释则寻找 bad-state covariance、cash-flow beta、investment factor、liquidity 和 time-varying beta；现有证据无法唯一识别。sector-neutral 通常降低波动但不保证提高收益，value 与 momentum/quality 互补，distressed “cheap” stocks 则可能持续亏损。
- **成立条件**：研究必须固定 PIT universe、country/accounting convention、valuation numerator/denominator、publication lag、rebalance、weighting、long/short/borrow、sector/size neutrality、benchmark beta、cost、capacity 和 corporate-action treatment。VMG、fundamental index、value spread、contextual model 与 cross-asset value 都是不同策略；每项需独立声明 signal、portfolio construction、risk neutralization、可交易工具和 OOS。style timing 必须预注册 momentum、spread、seasonal、macro/liquidity 变量与 horizon。
- **局限与反例**：FF VMG 对 small caps 给50%权重且不扣 short/funding cost，学术历史不是可实现组合；book-to-price 同时混合 expected cash flow 与 expected return。value 可多年失效，1999、2007—2008 展示拥挤和同步 deleveraging；cheap assets 在 liquidity crisis 中会更便宜。mean reversion 策略天然 short structural break，铁路、股债收益率关系、长期利率和 emerging-market rerating 等案例说明“历史锚”可能永久失效。refinement、value-spread timing 和季节性比基础规律更容易 data mine。
- **项目动作**：`EquityValueEvidence` 保存每个 valuation field 的 source/as-of/publication lag、composite rule、sector/size/country exposure、yield/growth/convergence/migration attribution、momentum/quality/distress filters、borrow/funding/turnover/impact、crowding/flow、downside/liquidity beta、structural-break falsifier 与 forecast interval。美股候选必须同时报告 raw 与 sector-neutral、long-only 与 implementable long–short、value-only 与 value+momentum/quality，并把 optimizer residual exposure 纳入 risk ledger。
- **禁止直接采用**：不得迁移4.1% value premium、历史 Sharpe、30%分位、50% small-cap 权重、任何 value-spread correlation、January effect、factor beta、fundamental-index 2%或 distress delay 规则；不得把便宜、低 P/B、长期反转或跨资产 mean reversion 自动变成仓位。无当前 PIT 数据、完整 delisting/failed-firm 样本、borrow/cost/capacity、独立 OOS 与结构断点压力时，不得实施或解锁 gate。
- **L3 待复核**：`FORM-PORT02-CH12-001`—`034`。

### 第 13 章：Currency Carry、坏状态保险与期限一致性

- **论证链**：FX carry 通过买高短率货币、卖低短率货币获取利差并承担未来 spot change；UIP 认为高息货币应贬值抵消carry，但历史 forward-rate bias 显示平均未完全抵消。动态重排比静态高息/低息持仓更能利用跨国利差时变；收益却呈“楼梯上、电梯下”的负偏度，在1987、1998、2008等flight-to-quality时期集中亏损。随着资金流入和产品化，不同carry pair相关、equity/downside beta 与crowding上升，使所谓alpha逐渐变成系统性坏状态beta。
- **成立条件**：研究必须固定 base/quote、spot/forward convention、deposit/forward maturity、signal与holding horizon、rank universe、peg/capital-control/default exclusions、rebalance、long/short notional、cash collateral、transaction/funding cost、vol scaling、country cap 与可执行时间。expected excess return 必须拆为 carry 与 `E(ΔS)`，PPP/value、momentum、yield change、survey和risk-aversion只是竞争代理；EM样本还要纳入高通胀、devaluation、convertibility与缺失失败国家。

### 第 21 章：Forward-Looking Measures 与三构件收益分解

- **论证链**：expected return不可观测，value/carry用当前价格相对cash-flow、yield、spread或历史anchor提供实时、简单但噪声较大的proxy；其优势是少模型、可观察，弱点是短期预测差且结构变化会移动anchor。跨资产可统一写成`carry + expected cash-flow growth + expected valuation change`：equity含payout与per-share growth，Treasury以yield/roll及固定现金流为主，credit还需扣default/downgrade与option，long–short策略需补回cash或明确excess-return口径。这个恒等式提供语义一致性，不保证各输入可准确预测。
- **成立条件**：每个指标必须固定price timestamp、fundamental/forecast vintage、currency、inflation、horizon、compounding、cash/excess/total return与benchmark。Equity需区分reported/operating、trailing/forward、1年/10年earnings、dividend/buyback/total payout及single/multi-stage DDM；bond需明确YTM/YTW/OAS、reference curve、duration/option model、reinvestment、recovery、real-yield deflator与survey/market inflation；carry需写明unchanged-market assumption、rolldown、financing、fees与tradeability。
- **局限与反例**：forward earnings常受乐观偏差，operating earnings系统性高于reported，单年trailing earnings在周期谷底会扭曲E/P；长期平滑又引入滞后。YTM假设持有到期且同率再投资，OAS依赖term-structure/vol model和data provider，raw spread仍混default、tax、liquidity与option；TIPS real yield不等于nominal bond expected real yield。valuation mean reversion弱且可能结构断裂，trend/HF等策略缺乏自然value anchor，`future equals past`只是无信息基线。
- **项目动作**：建立`ExpectedReturnBuildingBlocksEvidence`，逐资产保存carry/income/roll、cash-flow growth、valuation-change assumption、default/recovery、option cost、financing/cash、fees/slippage和residual uncertainty，并输出nominal/real/excess区间。美股需PIT earnings/payout/share-count与sector/cycle敏感度；BTC需按spot/perpetual/futures拆funding、basis/roll、collateral yield、fees与expected mark/spot convergence，不把funding直接视为alpha。Forecast层只消费经版本化的构件和区间，Portfolio/Risk保留model disagreement与zero-mean-reversion基线。
- **禁止直接采用**：不得迁移任何E/P、CAPE、DDM growth、real yield、BRP、OAS、spread、PPP、IV–RV或mean-reversion阈值；不得把high yield、steep curve、backwardation、high funding或cheap valuation直接等同expected return。未经PIT输入、会计/报价口径、default/option/financing、真实成本、结构断点与walk-forward验证，不新增策略、不调参、不解锁gate。

### 第 22 章：Carry/Yield Spread 的预期与风险溢价分解

- **论证链**：任何持有期实现收益都可拆为`carry + capital gain`，但远期价、远期利率和曲线斜率首先只是让不同资产回报相等的盈亏平衡量，不自动等于市场预期。风险中性解释要求未来汇率、收益率、增长或价格变化恰好抵消初始yield advantage；风险溢价解释则把利差视为所需回报差。更现实的分解是`carry = expected excess return + expected offsetting price/rate change`。书中互补回归把利差对未来价格/利率变化与未来超额收益的预测斜率限制为合计1；历史上FX、债券、信用、股票、商品、住房和波动率的carry多半更能预测后续收益，但这既可能来自时变理性风险溢价，也可能来自系统性预期偏误。
- **成立条件**：比较必须固定holding period、cash/riskless benchmark、spot/forward与报价方向、curve/contract snapshot、duration/convexity、cash collateral、roll/aging、default/recovery、embedded option、financing、transaction cost和price-return identity。互补回归需要同一信息时点、无泄漏的forward-implied change、可投资excess return、相容horizon、稳定测量定义及斜率和标准误；跨资产结论还需区分time-series与cross-section、constant-split假设、subperiod稳定性和bad-state loss。
- **局限与反例**：carry与capital gain边界会被pull-to-par、rolldown、commodity roll-up和option time decay模糊；YTM或rolling yield只是unchanged-curve/market shortcut。UIP/PEH被拒绝不证明carry收益完全理性，survey可显示预期偏误；互补回归的固定分解会掩盖时变系数。credit spread必含expected loss且受liquidity/option影响，商品backwardation可同时预示spot下跌和正收益，vol term structure也可同时含mean reversion与variance premium。极端通胀、拥挤去杠杆、默认、隐藏期权和销售费用能让高名义yield对应低甚至毁灭性实际收益。
- **项目动作**：建立`CarrySpreadInterpretationEvidence`，逐资产保存carry identity、break-even move、market/survey expectation proxy、expected excess-return residual、roll/aging、default/option/financing/cost、regression specification、coefficient uncertainty、subperiod drift、tail scenario和rational/mispricing/unresolved标签。BTC仅把perpetual funding、dated-futures basis、cash-and-carry和collateral yield按venue/contract/mark/settlement拆解，验证下一期mark/spot变化与净超额收益的“赛马”，并压力测试funding reversal、basis gap、liquidation、venue和crowding；美股valuation/yield需PIT fundamentals、payout/growth及sector/borrow/cost控制。所有结果只进入Forecast evidence，Portfolio/Risk决定仓位，OMS/ledger负责可实现收益对账。
- **禁止直接采用**：不得迁移FX、Treasury、credit、WTI、housing或variance的任何回归斜率、相关系数、Sharpe、rolldown数值、样本期或阈值；不得把forward、steep curve、backwardation、high earnings yield、high funding或inverted vol curve称为“市场预测”或保证alpha。未经PIT数据、定义对账、互补预测检验、成本/融资/default/option处理、rolling OOS、坏状态与capacity验证，不新增carry策略、不调参、不解锁gate。
- **L3 待复核**：`FORM-PORT02-CH22-001`—`048`。

### 第 23 章：Survey-Based Subjective Expected Returns

- **论证链**：市场预期通常不可直接观测，survey提供少数真正实时的主观ex ante证据；预测未来不准并不自动说明调查不能代表受访者或市场当时的看法。它与market-implied或econometric forecast回答的问题不同：调查测“人们认为会怎样”，估值和预测模型估“客观上可能怎样”。零售股票回报预期往往在上涨与好景气后升高、下跌与衰退后降低，呈顺周期外推；估值指标和理性风险溢价模型常给出逆周期预期。若调查可代表市场，二者分歧有助于把收益可预测性拆成时变风险溢价、系统预期误差或模型事后拟合，但不能单独完成因果识别。
- **成立条件**：每条survey evidence必须保存question wording、target variable、forecast horizon、field/start/end/publish date、respondent universe、response rate、mean/median/mode及完整分布、weighting、revision、market comparison timestamp和可投资return转换。代表性需针对具体市场与风险承担者定义，必要时按wealth/AUM或角色分层；point forecast需区分概率均值与base-case mode，并保留disagreement、uncertainty和skew。由yield减survey rate推导BRP时必须匹配期限、forward window、compounding和survey时点。
- **局限与反例**：talk-is-cheap、注意力不足、gaming和agency incentive会造成偏误；analyst earnings与pension assumptions可能系统乐观。经济学家调查可代表macro/short rates却不代表equity，民主平均也未必代表wealth-weighted market。机构使用“最新预测”会在survey date已陈旧，outlier/data error会扭曲均值，median会丢失尾部，mode会忽略共同认可的非对称风险。历史调查样本短、覆盖单一降息通胀时代，survey measurement error与model specification/estimation/hindsight error之间没有天然赢家。
- **项目动作**：建立`SubjectiveExpectationEvidence`，将survey与market-implied、valuation、econometric forecast分源保存，输出point、distribution、disagreement、skew、respondent coverage、staleness和measurement-error标签。美股可将retail、professional、CFO/analyst预期与PIT valuation、realized return并列检验外推偏误；BTC若无稳定代表性调查，不得用社媒情绪冒充market expectation，只能作为独立sentiment proxy并记录采样/机器人/平台偏差。混合模型可把survey作为噪声输入，但需rolling OOS证明相对单一baseline的净增益。
- **禁止直接采用**：不得迁移Philadelphia Fed、Blue Chip、Goldsmith–Nagan、WSJ、Consensus Economics、Yale或GMO的任何BRP/ERP、长期收益、通胀、年份、样本轮廓或资产排序；不得把survey consensus直接当真实概率均值、无偏forecast、全市场观点或交易信号。未经vintage、受访者代表性、时点匹配、分布恢复、成本和OOS验证，不新增sentiment/survey策略、不调参、不解锁gate。
- **L3 待复核**：`FORM-PORT02-CH23-001`—`028`。

### 第 24 章：Tactical Forecast 的模型、资产与实施边界

- **论证链**：战术预测可分为单资产/资产对timing与横截面selection，常把value、carry、momentum及宏观、供需、情绪、流动性和风险指标合成信号。二元投票、标准化回归、复合排名、横截面回归及Black–Litterman等方法在信息利用与稳健性之间权衡；复杂模型能利用signal strength、partial correlation和非线性，却不保证OOS优于简单baseline。最终目标不是最大化拟合或毛Sharpe，而是在明确horizon、现金基准、turnover、cost、liquidity、capacity和风险预算后得到可复现的净预测与组合决策。
- **成立条件**：所有预测器必须PIT可得，固定target return、benchmark、holding/trading frequency、universe、normalization window、estimation window、rebalance、position mapping、gross/net exposure、cash/short financing和execution lag。回归需只用当期可用数据rolling估计，记录intercept、coefficient constraints、standard error、predictor correlation与trial history；横截面模型需处理factor exposure测量误差、遗漏因子、非线性及universe变化。模型比较必须包含naive/equal-weight/binary/rank baseline，并用同一OOS、成本和风险口径评价。
- **局限与反例**：样本内回归高估predictability，rolling OOS仍不能消除指标选择的事后偏差；持久非平稳序列与长周期回归尤其易伪相关。标准化和`beta × Z`解释依赖窗口及统计条件，横截面“纯因子收益”受暴露噪声和模型遗漏影响，历史mean/intercept与factor premium会漂移。pairs/cointegration不保证关系回归，股市短中长期形态不自动迁移到BTC或其他资产。透明规则易复制，1998及2007—2008式共同去杠杆说明任何系统策略都可能因crowding、funding和liquidity同步失效。
- **项目动作**：建立`TacticalForecastExperiment`与`ModelTrialLedger`：保存hypothesis、feature lineage/vintage、target/horizon、universe、all tried variants、normalization/fit window、walk-forward splits、baseline、forecast interval、position transform、turnover、fees/slippage/borrow/funding、capacity、crowding和retirement rule。BTC按spot/perpetual/futures与venue拆数据、funding、mark、liquidation和24/7 execution；美股按PIT universe、delisting、sector/style、borrow与交易时段处理。Forecast只输出带不确定性的预测或排序，Portfolio/Risk负责组合、约束和no-trade，OMS/ledger核算真实成交与PnL。
- **禁止直接采用**：不得迁移1/−1、1/0、6个月、至少5年、SR 0.66、60% hit rate、任何rank cut、130/30、factor premium、regime或signal threshold；不得以“binary更稳健”“回归更聪明”“cross-section更多样化”替代本项目证据。未经预注册、PIT rolling OOS、全trial披露、成本/融资/shortability、capacity、crowding、参数稳定性及危机压力验证，不新增模型、不调参、不解锁gate。
- **L3 待复核**：`FORM-PORT02-CH24-001`—`047`。

### 第 25 章：Seasonal Regularities 的制度机制与衰减

- **论证链**：日历模式可发生在日内、周内、月内、月份、节假日、公告日、政治周期或真实供需季节。January effect最显著，历史上small cap、value、reversal、high-vol、credit与carry常在年初集中获利，而momentum可能反向；税损卖出、机构window dressing、奖金/回撤额度重置、年初risk appetite和节前流动性都可解释部分现象。January barometer与Hallowe’en effect可能共享“年初风险偏好较强”的机制，商品农业/能源季节则有更直接的库存、收获和需求基础。但观察到平均差异不等于存在净可交易收益。
- **成立条件**：每个季节假说必须固定exchange calendar、timezone、session、business-day convention、tax/fiscal year、holiday/announcement timestamp、asset/contract、return window、benchmark和执行时点。需要保留所有搜索过的月份、日期窗、国家、资产、方向及交互项，按discovery前后、subperiod、venue与制度变更做稳定性检验；同一日历窗口的overlapping return和11个非January月对1个January月等样本不平衡必须正确处理。商品还需同时建spot、futures curve、inventory、harvest/weather和roll PnL。
- **局限与反例**：金融史只有一条，季节切分极多，data mining和样本偶然性尤其严重；公开后交易者会提前布局，使January或turn-of-month前移、变弱或消失。许多纸面收益小于spread、impact和税费，低流动性报价反弹甚至可能没有实际成交。January equity/value近二十年符号曾反转，Monday effect公开后消失，presidential和policy cycle也衰减；liquidity对January的证据相互冲突，mutual-fund flow没有支持看似合理的月末资金解释。月相等缺乏机制的模式仅是低可信候选。
- **项目动作**：建立`CalendarEffectEvidence`与calendar trial family，保存hypothesis mechanism、calendar version、event timestamp、all tested windows、effective observations、pre/post publication、cost/capacity、subperiod及failure rule。美股使用真实交易日、半日市、公告/财报和税制版本；BTC按UTC与主要venue session、funding settlement、期货到期、周末/节假日全球流动性及24/7连续交易单独定义，禁止套用Monday/January标签。季节信息优先作为已有交易的execution deferral/avoidance guardrail；只有独立OOS净增益充分时才进入Forecast，且仍由Portfolio/Risk和OMS控制。
- **禁止直接采用**：不得迁移January、first days、November—April、4/5-day month turn、17—37个百分点、59%/14%、任何month/day方向、样本期或风险偏好阈值；不得因“January barometer”“Sell in May”、holiday、lunar或announcement momentum直接开仓。未经机制、完整trial ledger、真实日历、PIT时点、multiple-testing、成本、发现后样本和容量验证，不新增calendar策略、不调参、不解锁gate。
- **L3 待复核**：`FORM-PORT02-CH25-001`—`042`。

### 第 26 章：Cyclical Variation 与实时状态识别

- **论证链**：历史上risky asset excess returns在周期谷底附近较高、峰值附近较低，dividend yield、credit spread等前瞻指标常在扩张中下降、收缩中上升；这更可能混合cash-flow surprise、discount-rate repricing、countercyclical risk premium和政策传导，而不是简单的“衰退买、繁荣卖”。增长维度单独对股票区分度有限，通胀与波动状态更能解释股票和债券，增长对商品与住房更重要。策略风格也呈状态差异，但这些都是同期平均，只有能够用实时信息预测下一状态且关系稳定时才可能有投资价值。
- **成立条件**：周期研究必须保存macro release/vintage/revision、survey vintage、market timestamp、classification algorithm、state probability、transition date、decision lag和可执行return horizon。NBER峰谷是延迟确认的事后标签，只能用于描述或训练，不得直接进入实时回测；growth、inflation、volatility composite的构件、权重、标准化窗口、缺失序列和sign threshold必须版本化。realized return、valuation/carry indicator与unexpected macro move需分开，政策水平、预期和surprise也须分层。
- **局限与反例**：周期长度、深度和成因不稳定，战后普通衰退与balance-sheet recession不同；扩张样本远多于收缩，四象限也不均衡。书中composite与phase thirds属主观构造，部分数据只从1960s开始；同一regime内部早晚阶段表现可相反，bonds对volatility的关系在1980s后变号。1930s会改变value和inflation结论，最近政策周期中股票在降息期亏损、加息期上涨也反驳机械政策映射。预测macro regime本身非常困难，使用修订数据会制造严重lookahead。
- **项目动作**：建立`MacroRegimeEvidence`，输出as-of state probabilities而非确定标签，保存growth/inflation/volatility/liquidity/funding构件、release calendar、revision delta、transition uncertainty、asset/strategy conditional return及ex-ante indicator。美股重点比较PIT盈利/valuation、rates、credit和policy surprise；BTC需另建crypto-native activity、stablecoin/liquidity、funding、volatility和risk-off proxy，不能直接套NBER。每个regime enhancement作为独立trial进入rolling OOS，与无regime baseline比较净收益、turnover、tail和误分类成本；Portfolio/Risk只消费概率与压力情景。
- **禁止直接采用**：不得迁移NBER thirds、峰谷前后5个月、80%/20%、四象限sign cut、六指标等权、32bp/−45bp、任何资产/策略regime排序或历史样本期；不得用已知衰退、修订GDP、事后波动状态或“降息利好”生成信号。未经PIT vintage、概率状态、transition lag、结构断点、rolling OOS、成本和误分类压力验证，不新增regime timing、不调参、不解锁gate。
- **L3 待复核**：`FORM-PORT02-CH26-001`—`044`。

### 第 27 章：Secular Trend、结构断点与长期情景

- **论证链**：1988—2007的高资产收益同时受disinflation、宏观波动下降、杠杆扩张、financialization、估值抬升和stock–bond相关性改善推动，不能视为可持续常态。书中将free-market pendulum、disinflation、leverage、financialization和asset richening列为可能逆转，将技术进步、新兴经济体、老龄化、全球化和环境约束列为较持久趋势；这种二分本身是主观判断。长期回报必须把starting yield/carry、cash-flow growth、valuation change、default/inflation、政策与结构变化拆开；经济增长、国家崛起或宏大叙事不保证投资者回报。
- **成立条件**：每个secular scenario需明确as-of date、horizon、base case与至少两个替代情景、driver、observable signpost、传导路径、资产/现金流/估值影响、反证和更新规则。历史二十年对比必须报告端点敏感度、战争/危机/制度样本、nominal/real、valuation contribution和survivorship；debt/GDP、profit share、market-cap/GDP、inflation、yield与人口数据需保存vintage和定义。长期观点必须与当前价格分开：好增长若已高价反映可带来低回报，坏宏观若起始估值足够低也可能产生高回报。
- **局限与反例**：本章作者明确称分析impressionistic、discretionary和speculative，且紧贴2008—2010时点；2009反弹已反驳“危机将长期压低risk appetite”的即时判断。十个趋势的reversing/sustainable标签无统计识别，趋势彼此共线且因果方向不清；profits/GDP与valuation可能均值回归，也可能因上市比例和产业结构改变。通胀/通缩、财政、主权信用、监管、全球化与新兴市场路径存在宽尾分布；政策会内生响应。历史低yield、人口负担或债务上升并不能给出精确回报时点。
- **项目动作**：建立`SecularScenarioEvidence`，只保存scenario ranges、drivers、signposts、transmission graph、probability-free stress和disagreement，不输出伪精确expected return。美股情景拆profit share、payout/dilution、real growth、inflation、real yield、valuation、tax/regulation与sector composition；BTC拆adoption/usage、monetary/liquidity regime、regulation、energy/security、market structure和collateral demand，禁止用“数字黄金”“国家采用”等故事代替可观测证据。Portfolio/Risk使用情景做长期资本、相关性、通胀、流动性与主权/政策压力，不允许策略层按叙事直接生成OrderIntent。

### 第 28 章：风险、期限、技能与全成本的净收益目标

- **论证链**：组合表现只能从四条路径改善：承担更高或更优质的风险、利用真实长周期、识别并应用技能、降低无效成本。分散化降低variance drain并改善geometric return，若允许适度杠杆可把更高风险调整收益转成更高raw return；再平衡在特定相关性、收益差与成本条件下维持分散。长期资本可能赚illiquidity/term premium并在压力中供给流动性，但危机时期限会缩短。主动管理是成本前零和、成本后负和，技能稀缺且会被费用、AUM、capacity和选择偏差捕获。最终评价必须从毛Sharpe转为净复利与坏状态生存。
- **成立条件**：Portfolio objective必须声明arithmetic/geometric、nominal/real、gross/net、benchmark、target volatility、liability horizon、liquidity need、funding/haircut、rebalance rule、cost/tax和tail constraints。risk parity、vol targeting、rebalancing及fundamental-law计算需PIT volatility/correlation、独立breadth、IC uncertainty和可执行position；杠杆必须通过margin、cash ledger、forced-deleveraging与correlation-spike压力。manager skill需factor-adjusted、capacity/fee-adjusted、survivorship/backfill-aware，并比较time-weighted与dollar-weighted investor return。
- **局限与反例**：60/40风险集中、equal-vol、GM近似、diversification return、`IR=IC×sqrt(breadth)`和time diversification都依赖简化假设；相关性在危机中上升，杠杆会迫使低价去杠杆。rebalancing若资产长期收益差大或短期momentum强可拖累，交易成本决定最优频率。illiquid marks平滑使Sharpe虚高且真正需要现金时premium未必实现。高active share、历史alpha或HF dispersion可能来自隐藏beta、尾部、运气、报告偏差或事后选择；复杂度、欺诈、运营和税务风险无法被单一volatility捕捉。
- **项目动作**：建立`PortfolioObjectiveEvidence`、`RebalancingEvidence`、`ManagerSkillEvidence`和`AllInCostLedger`。BTC/美股组合统一输出expected net compound return、bad-state loss、drawdown、skew、liquidity/capacity、funding/margin、turnover和operational burden；再平衡、vol target和risk budget必须有no-trade band及真实fill对账。策略与经理评估保留全部trial、factor model、fees、borrow、impact、tax、lockup和redemption；若复杂方案不能相对equal-weight/low-cost baseline稳定改善净决策效用，则拒绝。
- **禁止直接采用**：不得迁移60/40、95%风险贡献、50/50 vol、0.40/0.38 Sharpe、0.76/0.96相关、GM/AM历史数值、rule of 72、15 worst months、carry/trend胜率、active-share、70bp、1.5%/3%—7%或任何杠杆、rebalance、vol target、经理费率阈值；不得把“long horizon”“risk parity”“portable alpha”当自然优势。未经liability、PIT risk、真实融资/成本/税、capacity、tail、OOS与治理验证，不新增组合增强、不调参、不解锁gate。

### 第 29 章：长期投资者的自然优势、约束与治理

- **论证链**：长期组合不应依赖单一equity或illiquidity premium，而应在value、carry、momentum/trend、liquidity、timing与可识别alpha之间分散，同时按坏状态损失和起始估值调整。显式适度杠杆可能比追逐内嵌杠杆、高波动或headline yield更透明，但必须能承受margin和去杠杆。真正长期资本可在风险厌恶和流动性需求高时逆向供给资本；若组织在压力中缩短期限、追涨杀跌或缺乏治理，这种优势不存在。
- **成立条件**：自然优势必须由liability cash flows、liquidity buffer、stable risk tolerance、AUM/capacity、governance、incentives、execution skill与countercyclical decision record证明。资产、策略与risk-factor allocation需同时看expected net return、valuation、tail timing、correlation、drawdown、fees和operational complexity。主动/被动、内部/外部、liquid/illiquid与timing/static选择必须匹配资源和base rate；目标收益必须随inflation、real yield与risk premium更新。
- **局限与反例**：equity-like endowment portfolios在2008暴露drawdown和illiquidity，绝对收益经理也并非免疫。diversification在危机中失效，style组合也会因crowding共同亏损；safe haven会随制度变化。主动管理成本前零和、成本后负和，large AUM既有议价能力也有impact/capacity限制。stop-loss或低风险能控回撤但通常牺牲expected return；事后看似错误的去风险在当时可能避免更深崩盘。固定8%或其他“需要的收益”会诱导过度风险和会计幻觉。
- **项目动作**：将全书落为Agent治理检查：Forecast输出多来源、区间和失效条件；Portfolio/Risk按factor、tail、liquidity、liability和capacity聚合；OMS/ledger核算真实融资、成本和PnL；promotion只接受current-HEAD证据。建立`NaturalEdgeEvidence`与`InstitutionalObjectiveEvidence`，要求每项优势有owner、observable、capacity、crisis behavior和falsifier；若治理、数据、权限或流动性不足，默认低成本baseline、constant weights、no-trade和fail-closed。
- **禁止直接采用**：不得迁移十类收益来源的yes/no结论、6—12月momentum、fallen angels、60/40、8%/10%目标、任何leverage、illiquidity、timing、factor或safe-haven配置；不得因“大型、长期、资源丰富”自我宣称edge。未经本项目PIT数据、净成本、容量、liability、危机行为、治理和OOS证据，不新增策略、不调参、不形成promotion结论。
