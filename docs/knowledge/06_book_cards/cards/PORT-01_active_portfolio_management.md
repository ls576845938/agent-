## 已完成 L2：第 1—22 章

### 第 1 章：主动管理闭环

- **论证链**：主动观点先转成 exceptional-return forecast，再与独立风险预测进入组合构建；实施成本、成交反馈和绩效归因决定研究优势能否兑现。benchmark 同时定义比较基准和授权边界，因此 active return/risk 比只看绝对收益更适合机构化流程。
- **成立条件**：benchmark、预测周期、风险模型、数据版本、成本口径和决策时间必须预先确定；研究、构建、实施和归因使用兼容的语义。
- **局限与反例**：市场非平稳、历史数据脏、真实交易会影响价格；好 forecast 可被错误组合或成本吞噬，复杂模型也不能修复错误输入。
- **项目动作**：保持 `Signal → Forecast → TargetPosition/OrderIntent → Risk/OMS → Fill/Ledger → Attribution` 闭环；ForecastEvidence 必须携带 benchmark、horizon、uncertainty 和校准版本。
- **禁止直接采用**：不得把 `alpha = volatility × IC × score`、经验 IR 或“价值与 IR² 成正比”当生产常数；不得让 Strategy 绕过 Portfolio/Risk 和 OMS。
- **原 PDF 复核结论**：已逐页核对 PDF 物理页 `9-16`（书页 `1-8`）。`FORM-PORT01-CH01-001` 对应 PDF 9—14 页，benchmark-relative active/residual return、risk、IR 与 mean-variance value-added 框架已核；IR² 与 value-added 的关系只在后续章节给定偏好、单位和机会集假设下成立，不能当经验事实。`FORM-PORT01-CH01-002` 对应 PDF 14—15 页，`IR = IC × √breadth` 在本章仅为全书导论，独立 breadth、skill 估计和实现条件仍以第 6 章推导为准。`FORM-PORT01-CH01-003` 对应 PDF 15—16 页，`Alpha = residual volatility × IC × standardized score` 明确为 rule of thumb；score 标准化、residual-volatility 口径、IC 校准与无信息时回 benchmark 必须训练期/OOS 另证。3 项均标记 `verified_concept_only`，且本章同时确认 forecast、portfolio construction、trading cost 与 performance feedback 的闭环不能被单一公式替代。

### 第 2 章：CAPM 共识基线

- **论证链**：收益可先分成 benchmark/systematic 与 residual；CAPM 进一步把预期 residual return 设为零，从而形成共识预期收益基线。经理人的 alpha 是相对该基线的前瞻偏离，而历史回归 alpha/beta 只是实现估计。
- **成立条件**：必须声明 benchmark、风险自由资产、预测 beta、风险溢价、频率和均值—方差假设；反向优化还要求把给定组合视作所选模型下的有效组合。
- **局限与反例**：CAPM 是预期收益模型而非完整风险模型；历史均值标准误巨大，企业和投资集合会变化；理论市场组合包含所有资产，实务 benchmark 只是近似。
- **项目动作**：CAPM/隐含均衡收益仅作 baseline 或 scenario；分开记录 forward beta 与 realized beta，并对估计误差、收缩和结构变化做敏感度分析。
- **禁止直接采用**：不得把 residual 自动命名为真实 alpha；characteristic/pure portfolio 通常杠杆化、long-short 且不可投资，只能作为诊断对象。
- **原 PDF 复核结论**：已逐页核对 PDF 物理页 `18-47`（书页 `11-40`，含技术附录）。`FORM-PORT01-CH02-001` 对应 PDF 18—24 页，systematic/residual 分解、forward beta 与 `E[r_P]=β_P E[r_M]` 的 CAPM consensus expected-return 关系已核；分解本身不需要 CAPM，但 residual expected return 为零需要 CAPM 假设，且 CAPM 是 expected-return baseline 不是完整风险模型。`002` 对应 PDF 19—20、26—30 页，历史均值标准误、historical alpha/beta、回归到均值和 beta forecast 已核；历史回归估计不等于前瞻 beta，书中旧 BARRA 数值和样本不能迁移。`003` 对应 PDF 30—33 页，security market line 的 ex ante 直线与 ex post realized scatter 已核；实现散点、一次 residual return 或“不拒绝 CAPM”均不能证明当前预期关系。`004` 对应 PDF 33—38 页，characteristic portfolio 的最小方差单位暴露、矩阵逆和缩放性质已核；其依赖非奇异 covariance，可含 long/short 与高杠杆，只作 exposure diagnostic。`005` 对应 PDF 38—43 页，minimum-variance、maximum-Sharpe 与 fully invested efficient frontier 已核；技术附录明确不施加 long-only 约束，也未包含成本、容量和估计误差。`006` 对应 PDF 40—45 页，alpha characteristic portfolio、expected-return reverse mapping 与 CAPM theorem 已核；`Q=M` 依赖 mean-variance preferences、全资产、同质 expected returns/covariance、无税费、风险自由借贷和市场清算。6 项均标记 `verified_concept_only`，当前项目只能把 CAPM 用作版本化 consensus baseline/challenger，不能把旧参数、理论市场组合或无约束解当成可投资组合。

### 第 3 章：风险模型与风险归因

- **论证链**：标准差之所以被采用，是因为可聚合和相对易预测，不代表它充分描述尾部。组合风险来自协方差；结构化因子模型再把共同因子与 specific risk 分开，用于当前风险诊断、未来风险预测和历史归因。
- **成立条件**：暴露必须在决策时点可得；因子收益、因子协方差、specific risk、benchmark、horizon 和模型版本必须一致。共同因子与 specific return 不相关、specific return 相互不相关均是模型假设。
- **局限与反例**：正态和平方根时间缩放需要分布、独立性与平稳性条件；历史协方差在短样本和 `T≤N` 时不稳定或奇异；压力期 specific return 与相关性可能共同上升。
- **项目动作**：RiskEvidence 同时报告 total/active/residual risk、factor exposure、specific risk、边际风险、模型版本和估计误差，并补充 shrinkage、正定性、集中度、流动性、gap/downside 和 stress correlation。
- **禁止直接采用**：不得把横截面 momentum/value 等风险暴露解释为必然预期收益；pure factor portfolio 和旧 BARRA 案例只用于诊断，不作为可交易组合或当前验证。
- **原 PDF 复核结论**：已逐页核对 PDF 物理页 `48-94`（书页 `41-86`，含技术附录、应用讨论、习题与参考文献）。`FORM-PORT01-CH03-001`—`004` 对应 PDF 48—62 页，standard deviation、semivariance/target semivariance、shortfall/VaR、covariance diversification、平方根时间缩放、active/residual risk、risk-aversion penalty 及 historical covariance 的样本/rank 限制已核；正态换算、无自相关缩放和 `T>N` 只是条件，不能覆盖尾部、gap、流动性、结构变化或估计误差。`005` 对应 PDF 62—72 页，structural factor model 的 return decomposition 与 `V=XFX'＋Δ` 已核；factor/specific orthogonality、specific return 相互不相关和稳定 PIT exposure 均为模型假设，旧行业/风格分类与 BARRA 数值不可迁移。`006`—`009` 对应 PDF 79—92 页，cross-sectional GLS factor-return estimation、factor portfolio、factor/specific covariance forecast、total/active/residual decomposition、asset/factor/sector marginal contribution 与 risk attribution 已核；GLS 权重、factor identification、diagonal specific covariance、边际方向和 sector aggregation 都需版本化，归因不是因果。9 项均标记 `verified_concept_only`；当前 `RiskEvidence` 必须保存 as-of、benchmark、holdings、exposure/covariance/specific-risk model、PSD/rank/conditioning、total/active/residual/model-external stress 与 reconciliation，且任何风险输出只进入 Portfolio/Risk。

### 第 4 章：benchmark、择时与 value added

- **论证链**：预期收益可拆成 time premium、benchmark risk premium、exceptional benchmark return 和 alpha；前两者形成基线，后两者分别对应 benchmark timing 与 stock selection。机构经理对偏离 benchmark 的业务风险通常高于对 benchmark 自身风险的厌恶。
- **成立条件**：benchmark 必须代表授权范围；active beta、residual position 和风险厌恶参数必须使用同一频率和单位。`beta=1` 时 active 与 residual return/risk 才重合。

### 第 5 章：IR、机会集与风险预算

### 第 7 章：APT 与因子收益预测
